Pinocador Auto

Ferramenta pessoal do streamer Pinocador · Última atualização: 28 de outubro de 2026

O que é

O Pinocador Auto é um programa que roda no computador do próprio Pinocador. Ele transforma trechos das lives do canal twitch.tv/pinocador em vídeos curtos e envia esses vídeos para o canal do YouTube do próprio Pinocador. Não é um serviço aberto ao público: não há cadastro, venda nem outros usuários.

Política de privacidade

  • Quais dados do Google são usados: a permissão para enviar vídeos (youtube.upload) e para ler as estatísticas do próprio canal (youtube.readonly).
  • Para quê: publicar os cortes no canal do dono e ver quantas visualizações eles tiveram, para escolher melhor os próximos cortes.
  • Onde ficam: o acesso fica salvo só no computador do dono. Nada é enviado para servidores do Pinocador Auto (eles não existem).
  • Compartilhamento: nenhum dado é vendido, compartilhado ou usado para anúncios.
  • Como remover: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Termos de uso

O Pinocador Auto é de uso pessoal do dono do canal. Quem o usa é responsável pelos vídeos que publica e por seguir os Termos de Serviço do YouTube. O programa é oferecido como está, sem garantias.
